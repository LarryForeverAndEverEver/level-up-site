# level-up-site

Public pages for the Level Up app (the game's code lives in a private repo).
Served with GitHub Pages from `main`, root folder.

- `privatliv/` – the privacy policy linked from Google Play. It must match
  what the app does: if the app ever sends data anywhere, this page changes in
  the same version (see AFKLARING.md in the game's repo, "Valgt 7/11: helt
  standalone").
